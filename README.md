# חפ"ק ניווטים

אפליקציית שליטה לשבוע ניווטים במכינה: טבלת שליטה חיה, מפת צירים, שעות גג, תדריכים, נוכחות ותפקידים, נקודת החלטה, מעבר חובה, לוגיסטיקה ומים, יומן אירועים, כרטיסי חניכים ותחקיר.

הקובץ `index.html` הוא האפליקציה כולה. פותחים אותו בדפדפן, והנתונים נשמרים במכשיר שפתח אותו.

## לראש שלוחה

1. פותחים את הקישור בטלפון של החפ"ק ומוסיפים למסך הבית.
2. "עוד", "הגדרות": שם השלוחה, חוליות ושמות, מדריכים, טלפונים. אם הניווט ברמות מנשה, הצירים כבר בפנים. אזור אחר: מחליפים נקודות קבועות וצירים באותו מסך.
3. בסוף כל יום: "סיכום זמנים", "הורד CSV".

## קבצים

- `index.html`: האפליקציה, ללא שמות (תבנית).
- `src.html`: קוד המקור עם מקומות להזרקת הגדרות.
- `config-template.json`: הגדרות ברירת המחדל (צירים ונקודות של רמות מנשה).
